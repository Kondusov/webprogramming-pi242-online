Запуск
1. Запустите WebSocket-сервер
Из корня проекта:

bash
php server/ws-server.php
Ожидаемый вывод:

text
Мессенджер запущен на ws://0.0.0.0:8080
HTTP API для логина: http://localhost:8000/api.php
2. Запустите HTTP-сервер для фронтенда
Из папки public/:

bash
cd public
php -S localhost:8000
3. Откройте браузер
Перейдите на http://localhost:8000.

Вкладка 1 — регистрация: alice / secret1.

Вкладка 2 — регистрация: bob / secret1.

Дальше:

alice создаёт группу «Разработка», открывает её через «Участники» → добавляет bob (по имени).

bob создаёт канал «Новости», добавляет alice. Пишет только владелец — alice может попробовать отправить сообщение, увидит ошибку.

alice создаёт личный чат с bob через + Личный.

alice открывает группу, кликает 🗑 у сообщения — удаляется у всех.

alice удаляет bob из группы через «Участники» → «Исключить» — у bob чат исчезает.

4. Проверка БД
bash
sqlite3 data/chat.db
sqlite> SELECT id, chat_id, user_id, substr(text,1,40), deleted FROM messages;
sqlite> SELECT * FROM chat_members;
sqlite> SELECT * FROM dm_pairs;
Все данные сохраняются — при перезапуске сервера и обновлении вкладки чаты и сообщения остаются.
